## ✨ 核心特性

### 1. 🌐 HTML 网页原生自解密加固 (零外部库依赖)
- **无需任何第三方外部库**：生成的加密 HTML 包含自包含轻量执行引擎，仅依赖浏览器内置原生 API（`TextDecoder`、`atob`、`document.write`），**离线无网即可毫秒级自解密渲染**。
- **本地双击即用**：生成的文件无论是直接在**本地双击打开（file:// 协议）**还是部署在任意服务器、Cloudflare Pages/Workers 上，均能即时完美解密渲染。
- **防审查与反爬虫**：访客右键查看源代码仅见密文加载器，无法提取任何 DOM 结构、CSS 样式与文本明文。

### 2. ⚡ JavaScript 脚本极致稳定混淆 (二次混淆自适应)
- **零 CPU 启动开销自适应**：智能检测超大脚本（>80KB）与预混淆特征，自动停用嵌套全局字符串字典，彻底杜绝 Cloudflare 启动 CPU 超限 523 报错。
- **顶层全局宿主垫片自动注入**：自动识别并注入 `var window = typeof globalThis !== 'undefined' ? globalThis : ...`，解决因第三方已混淆脚本直接访问裸 `window` 导致的 10021 错误。
- **原生 ES Module 强保护**：深度保护底层网络套接字导入与 `export default` 模块规范。

### 3. 🎨 国际化大气 UI 与交互升级
- **极具纵深的暗夜极光微流光背景**：支持白天（冰晶纯白玉石质感）与黑夜（深邃黑曜石微流光质感）一键平滑切换，自动持久化记忆。
- **科技仪表盘微徽章卡片**：实时展示今日加固次数、全网累计保护代码量及自愈修复成功率。
- **双列 IDE 工作台**：Mac 风格三色圆点装饰，行数/字符数晶体徽标，支持拖拽文件与代码实时智能感应。
- **企业级使用指南与说明白皮书**：卡片式开阔排版，图标与文字排版相得益彰。
