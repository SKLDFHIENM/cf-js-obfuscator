### 2. ⚙️ 自定义保护清单 / 保留字列表
- 提供高级自定义输入框，允许用户以逗号或空格分隔自定义**绝对不被重命名的关键字列表**（如特定的环境变量名、路由方法名或动态属性），杜绝 AST 重命名误伤动态调用的属性。

### 3. 🩺 Cloudflare Workers 专属能力深度补强
- **专属环境兼容体检报告（Cloudflare Diagnostics）**：
  - 一键输出健康体检清单，包含：
    1. **模块入口检查**：是否具备标准的 `export default { async fetch(...) }` 或 `addEventListener('fetch', ...)`；
    2. **全局宿主兼容性**：检查是否裸调用了 `window`/`document`，确认顶层兼容垫片注入状态，杜绝 10021 错误；
    3. **受限语法检测**：扫描并警示动态 `eval`、`new Function`；
    4. **底层 Socket 通信完整性**：检测并保护 `import { connect } from 'cloudflare:sockets'` 导入；
    5. **环境变量绑定自动扫描锁定**：自动识别源码中的 `env.KV_STORE`、`env.D1` 等常见绑定名，并在混淆中自动加入保护清单！
