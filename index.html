📖 WebShield 加固规范与使用指南

🌐 HTML 原生自解密加固

• 零外部库依赖：加密后的 HTML 包含独立自解密执行引擎，完全使用原生浏览器 API，无需任何外部 CDN 或 JS 库。

• 本地离线即开即用：生成的文件无论是直接在本地双击打开（file://）还是部署在任何静态托管服务上，均能即时完美解密渲染。

• 源码防审查防爬虫：右键“查看网页源代码”时只可见一屏密文加载器，无法提取任何原始 DOM 和明文。

⚡ JavaScript 脚本极致稳定混淆

• 二次混淆自适应：检测到超大脚本（>80KB）或已具有洗牌逻辑的代码时，自动开启 0ms 启动优化，杜绝 Cloudflare 启动 CPU 超限 523 报错。

• 跨环境 window 宿主垫片：自动注入全局兼容层，彻底解决裸引用 window 导致的 10021 错误。

• 原生 ES 模块保护：深度保护 import/export 语句，确保底层网络套接字通信链路正常。

🔒 深度代码装甲模式

• 全量字符串 Base64 字典化：将 URL、API 端点、配置项转化为加密数组并结合洗牌旋转。

• 字符串切块与乱序：将敏感关键字切碎编码，彻底规避关键词静态审查与文本比对。

📝 // 单行注释智能翻译与改写

• 精准语义转换：自动将 // 后的英文技术注释翻译为规范中文；已有中文注释自动同义语义改写（改变说法，不改意思）。

• 零破坏安全保障：非注释的业务代码 100% 保持原生 AST 与逻辑，零语法风险。
